# Play Clipper

Watch any game play by play without scrubbing a 3.5-hour video.

- `index.html` — the app (moved from Claude Design "Play Clipper v9")
- `support.js` — the page runtime; `vendor/` — React 18.3.1
- `Roadmap.md` — product and roadmap; `CLAUDE.md` — clip rules and backlog

Runs as a static site (GitHub Pages). ESPN play-by-play loads straight from the game link.
